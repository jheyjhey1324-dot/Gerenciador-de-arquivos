# ⚙️ Gerenciador de Arquivos

Aplicação em Python para cadastrar, acompanhar e organizar documentos de um portfólio. 
Com uma interface amigável, é possível adicionar, listar, atualizar, buscar e excluir itens, mantendo o histórico de alterações.


## 👩🏻‍💻 Sobre o projeto

O Gerenciador de Arquivos foi desenvolvido como um projeto prático de aprendizado da matéria de Raciocínio Computacional de Análise e Desenvolvimento de Sistemas, como linguagem prática focada em Python.
Aplica-se nele conceitos de lógica de programação, funções, manipulação de arquivos e tratamento de erros em uma situação do mundo real: acompanhar o andamento de projetos de fotografia.
O programa também tem um menu personalizada, com título em ASCII art e interface no terminal, para tornar a experiência de uso mais agradável.
